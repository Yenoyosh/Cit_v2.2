# Changelog

## v2.2 QUALITY CAMERA-CHAT

- Kamera-Chat ergänzt: eigene Kamera im Chat teilen.
- Kamera der Gegenstelle kann angefragt werden.
- Gegenstelle muss Kamera-Freigabe bestätigen.
- Chat-Meldung beim Kamera-Start/Stopp: `[KAMERA] <IP> hat die Kamera gestartet/gestoppt`.
- Mehrere Remote-Kameras können gleichzeitig in eigenen Tabs angezeigt werden.
- Remote-Kamera kann im Vollbild geöffnet und wieder geschlossen werden.
- Kamera-Teilen kann jederzeit gestoppt werden.
